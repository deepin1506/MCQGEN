# MCQGEN - Generative AI MCQ Generator

A Python project for learning Generative AI by building a multiple choice question generator.

## Getting Started

1. Ensure Python is installed (you have it via `py`).
2. Python extension is installed in VS Code.
3. Run `py main.py` to see a sample output.
